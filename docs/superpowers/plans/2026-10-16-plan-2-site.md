# On the Record: Website Implementation Plan (Plan 2 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the public website in `site/`: an Astro static site that reads the pipeline's `data/site/` contract and publishes every transcript, senator, bill, browse and search page, in the approved Citator design on desktop and phone.

**Architecture:**
- **Pipeline first.** Tasks 1–2 add the few fields the approved mocks need to the Python pipeline:
  - a transcript index
  - debate excerpts
  - hearing page numbers for bill mentions
  - senators' recent remarks
  - bill co-sponsors, committee and votes by senator
  - official page addresses
- **Static pages.** The site is static HTML generated by Astro from those JSON files. Interactive parts are small React islands mounted on that HTML, so the text stays real, searchable, printable and findable with the browser's Find:
  - speaker cards
  - citation tools
  - remark navigation
  - export
  - search
  - shortcut suggestions
- **Search** is Pagefind, plus a query layer in the browser. Each remark is a heading with an `id`, so Pagefind returns results per remark, and the query layer reads each result's `anchors` and `content` to apply phrases, NOT, NEAR and "only this speaker".
- **One build script** (`site/scripts/build.mjs`) runs Astro's `build()` and Pagefind's Node API, so builds behave the same on Windows and in CI.

**Tech stack:**
- Astro 7.4.0, @astrojs/react 7.1.0, React 19.3.1, Tailwind CSS 4.3.3 (through @tailwindcss/vite)
- Pagefind 1.5.2
- Vitest 5.0.5, Playwright 1.64.1
- fonts: @fontsource-variable/archivo 5.3.0, @fontsource/charis-sil 5.3.0
- pipeline side: Python 3.11+ with pytest, unchanged

**Spec:** `docs/superpowers/specs/2026-10-15-on-the-record-design.md`. This plan covers:
- sections 8 and 9.1
- the site rows of sections 10–12
- the site-data fields that section 7 now lists

Plans 3 and 4 cover automation and hosting, and the SQLite search experiment.

## Global Constraints

- **Colors** (spec 8.1):
  - stone ground `#F3F4F1`, white reading panes `#FFFFFF`
  - ink `#161B22`; secondary text `#4B535E` and `#666D77`; rules `#D7DBDF` and `#E9EBED`
  - highlighter `#FFE36E` on search hits
  - ledger green `#0B6B50`, **only on actionable things**
  - pennant flags: red `#B42318` for vetoed, amber `#9A6200` for corrected or amended, hollow ink for passed
- **Type:** Archivo for the interface, with tabular figures for dates, pages and counts. Charis SIL for every spoken word.
- **Reader:**
  - Speaker labels sit inline before the speech: uppercase Archivo 12.5px, then a **14px gap**.
  - Senators are underlined and open a card; procedural voices are not underlined.
  - Page breaks show inline as **`p. 5781`** with a dashed rule. The page a turn starts on appears in the gutter.
- **From user feedback:**
  - no multicolor speaker identity system
  - no dark masthead
  - no boxed-card restyle
  - refinements stay subtle
  - no motion in the search box
- **Copy with cite**, legal style by default:
  - floor: `N.Y. Senate Tr., June 10, 2025, at 5780 (remarks of Sen. Ortega)`, or `at 5780–81` across two pages
  - hearing: `N.Y. Senate Pub. Hr'g Tr., {title}, Mar. 18, 2025, at 112 (remarks of Sen. Okafor)`
  - **Plain**, in the same menu: `NY Senate floor transcript, June 10, 2025, p. 5780 (Sen. Marisol Ortega)`, or `NY Senate public hearing, {title}, March 18, 2025, p. 112 (Sen. Adaeze Okafor)`
- **Messages, word for word:**
  - plain-text fallback: "Speaker details aren't available for this transcript"
  - search failure: "Search couldn't load. Check your connection and try again."
  - old bills: "Full details not available for bills before 2009"
  - corrected flag: "Corrected transcript"
- **Exports** are made in the browser when clicked (Markdown, text, print to PDF). No export files are stored.
- **Pages never call the NY Senate API.** The site reads only `data/site/` at build time; the API key never reaches `site/`.
- **Size:** the built `dist/` warns above **800 MB** and refuses to publish above **950 MB**.
- **Hosting:** GitHub Pages, possibly under a project path such as `/ontherecord/`. Every internal link, image, JSON file and the Pagefind bundle goes through the base-path helper, never a hard-coded `/`.
- **Name:** the site name lives in one setting (`site/src/config.ts`, "On the Record").
- **No "unofficial" notice.** No formal accessibility target; ordinary good practice still applies (real text, headings, labelled buttons, keyboard access).
- **Mobile** follows `mobile.html` at 390 px:
  - hover becomes tap, and the speaker card and citation tools are bottom sheets
  - there is no horizontal page scroll

## Review Focus

These are the inputs most likely to break pages that no single feature test would naturally cover. Each one has a test in the task that owns the code.

1. **A transcript without speakers**, either plain-text fallback or empty, must render with the note "Speaker details aren't available for this transcript", produce no remark headings, and still build. Task 3 adds a synthetic plain-text transcript to the fixtures; Task 8 tests it.
2. **Speakers with missing details:**
   - senators without a photo, including all pre-2009 history senators (ids 100001+)
   - speakers with no senator match
   - Assembly-only speakers

   These must render cards and pages without broken images or links (tests in Tasks 9 and 11).
3. **Bills with no detail card or no bill number:** bills before 2009, and special-session readings whose `printNo` is `null` (the real 2009-06-23 fixture has them). They must render without crashing; bill pages show "Full details not available for bills before 2009" (tests in Tasks 8 and 12).
4. **A remark link whose anchor no longer exists**, after a corrected transcript. The page must land at the top with a notice instead of silently showing nothing (test in Task 10).
5. **The site served under a base path.** A build with `SITE_BASE=/ontherecord/` must have no broken internal link, image, JSON or Pagefind request (the link check and an end-to-end test in Task 17).

def _clip(text: str, limit: int) -> str:
    """One line of at most limit characters, cut at a word, with an ellipsis when cut."""
    text = " ".join(text.split())
    if len(text) <= limit:
        return text
    cut = text.rfind(" ", 0, limit)
    return text[: cut if cut > limit // 2 else limit].rstrip(" ,;:") + "…"

```python
"""Official Senate and Assembly page addresses, derived from names, with reviewed fixes.

The Senate site answers automated requests with 403 for some valid pages, so addresses are not checked on
every run; `python -m nyleg check-official` lists suspects for a person to review."""
from __future__ import annotations

import re
import time
import unicodedata
from collections.abc import Callable
from pathlib import Path

import httpx
import yaml

from .senators import HISTORY_ID_START
from .store import slugify

SENATE = "https://www.nysenate.gov/senators/"
ASSEMBLY = "https://nyassembly.gov/mem/"


def official_url(chamber: str, member_id: int, full_name: str, overrides: dict[str, str | None]) -> str | None:
    key = f"{chamber}:{member_id}"
    if key in overrides:
        return overrides[key]
    if chamber == "senate":
        # Senators who left before 2009 come from data/rosters and have no API record or official page.
        return None if member_id >= HISTORY_ID_START else SENATE + slugify(full_name)
    folded = "".join(c for c in unicodedata.normalize("NFKD", full_name) if not unicodedata.combining(c))
    return ASSEMBLY + "-".join(re.sub(r"[^\w\s-]", "", folded).split())


def load_official_overrides(path: Path) -> dict[str, str | None]:
    """Reviewed fixes: [{member: "senate:401", url: "https://..." or null}]."""
    if not path.exists():
        return {}
    rows = yaml.safe_load(path.read_text(encoding="utf-8")) or []
    return {str(row["member"]): row.get("url") for row in rows}


def check_urls(urls: list[tuple[str, str]], client: httpx.Client, pause: float = 1.0,
               sleep: Callable[[float], None] = time.sleep) -> list[tuple[str, str, int | str]]:
    """(name, url, status) for every address that does not answer 200, one request per `pause` seconds."""
    problems: list[tuple[str, str, int | str]] = []
    for name, url in urls:
        try:
            status: int | str = client.head(url, follow_redirects=True).status_code
            if status == 405:
                status = client.get(url, follow_redirects=True).status_code
        except httpx.HTTPError as exc:
            status = type(exc).__name__
        if status != 200:
            problems.append((name, url, status))
        sleep(pause)
    return problems
```

```ts
// Build-time access to data/site (Node only). Small files are cached; transcripts are read fresh each time.
import { existsSync, readdirSync, readFileSync } from "node:fs";
import { join, resolve } from "node:path";
import { BILL_DATA_START } from "../config";
import type {
  AssemblyMember, BillEntry, Meta, SenatorIndexEntry, SenatorPage, Transcript, TranscriptSummary,
} from "./types";

export const DATA_DIR = resolve(process.env.OTR_DATA ?? join(process.cwd(), "..", "data", "site"));

const cache = new Map<string, unknown>();

function readJson<T>(rel: string): T {
  return JSON.parse(readFileSync(join(DATA_DIR, rel), "utf-8")) as T;
}

function cached<T>(key: string, load: () => T): T {
  if (!cache.has(key)) cache.set(key, load());
  return cache.get(key) as T;
}

export const meta = () => cached("meta", () => readJson<Meta>("meta.json"));
export const transcriptIndex = () => cached("index", () => readJson<TranscriptSummary[]>("transcripts.json"));
export const transcript = (slug: string) => readJson<Transcript>(`transcripts/${slug}.json`);
export const senators = () => cached("senators", () => readJson<SenatorIndexEntry[]>("senators.json"));
export const senatorPage = (slug: string) => readJson<SenatorPage>(`senators/${slug}.json`);
export const assembly = () => cached("assembly", () => readJson<Record<string, AssemblyMember>>("assembly.json"));

export const senatorsBySlug = () => cached("bySlug", () => new Map(senators().map((s) => [s.slug, s])));
export const senatorsByMemberId = () => cached("byId", () => new Map(senators().map((s) => [s.memberId, s])));
export const senatorPageSlugs = () =>
  cached("pageSlugs", () => new Set(readdirSync(join(DATA_DIR, "senators")).map((f) => f.replace(/\.json$/, ""))));

export const billSessions = () =>
  cached("sessions", () => readdirSync(join(DATA_DIR, "bills")).map((f) => Number(f.replace(/\.json$/, ""))).sort((a, b) => a - b));

export const billsFor = (session: number) =>
  cached(`bills-${session}`, () => readJson<{ session: number; bills: BillEntry[] }>(`bills/${session}.json`).bills);

export function bill(session: number, base: string): BillEntry | undefined {
  const map = cached(`billmap-${session}`, () => new Map(billsFor(session).map((b) => [b.basePrintNo, b])));
  return map.get(base);
}

/** Every bill from 2009 on gets a page; earlier bills only when read on the floor (they have debates, no details). */
export function billPages(): { session: number; base: string; printNo: string }[] {
  return billSessions().flatMap((session) =>
    billsFor(session)
      .filter((b) => session >= BILL_DATA_START || b.segments.length > 0)
      .map((b) => ({ session, base: b.basePrintNo, printNo: b.card?.printNo ?? b.basePrintNo })),
  );
}

/** The latest session with bill details: the default for the bills list and "Most debated". */
export const currentSession = () => Math.max(...billSessions().filter((s) => s >= BILL_DATA_START));

export function years(): { year: number; count: number }[] {
  const counts = new Map<number, number>();
  for (const t of transcriptIndex()) counts.set(Number(t.date.slice(0, 4)), (counts.get(Number(t.date.slice(0, 4))) ?? 0) + 1);
  return [...counts].map(([year, count]) => ({ year, count })).sort((a, b) => b.year - a.year);
}

export function words(prefix: string): Record<string, number> {
  const rel = `words/${prefix}.json`;
  return existsSync(join(DATA_DIR, rel)) ? cached(rel, () => readJson<Record<string, number>>(rel)) : {};
}

// Display formatting shared by pages and islands: no Node or browser APIs beyond Intl.
import { RECORDS_START } from "../config";
import type { BillCard, ServicePeriod } from "./types";

const MONTHS = ["January", "February", "March", "April", "May", "June", "July", "August", "September", "October", "November", "December"];
const SHORT = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"];
const LEGAL = ["Jan.", "Feb.", "Mar.", "Apr.", "May", "June", "July", "Aug.", "Sept.", "Oct.", "Nov.", "Dec."];
const DAYS = ["Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"];

function ymd(iso: string): [number, number, number] {
  const [y, m, d] = iso.slice(0, 10).split("-").map(Number);
  return [y, m, d];
}

export const longDate = (iso: string) => { const [y, m, d] = ymd(iso); return `${MONTHS[m - 1]} ${d}, ${y}`; };
export const shortDate = (iso: string) => { const [y, m, d] = ymd(iso); return `${SHORT[m - 1]} ${d}, ${y}`; };
export const legalDate = (iso: string) => { const [y, m, d] = ymd(iso); return `${LEGAL[m - 1]} ${d}, ${y}`; };
export const dayDate = (iso: string) => {
  const [y, m, d] = ymd(iso);
  return `${DAYS[new Date(Date.UTC(y, m - 1, d)).getUTCDay()]}, ${SHORT[m - 1]} ${d}`;
};

export const pageLabel = (page: number) => `p. ${page}`;

/** Legal page spans drop repeated leading digits but keep at least two: 5780–81, 5798–802. */
export function legalPages(start: number, end?: number | null): string {
  if (end == null || end === start) return String(start);
  const a = String(start), b = String(end);
  if (a.length !== b.length) return `${a}–${b}`;
  let i = 0;
  while (i < a.length - 2 && a[i] === b[i]) i++;
  return `${a}–${b.slice(i)}`;
}

export const plainPages = (start: number, end?: number | null) =>
  end != null && end !== start ? `pp. ${start}–${end}` : `p. ${start}`;

export function serviceText(periods: ServicePeriod[]): string {
  if (!periods.length) return "";
  if (periods.length === 1) {
    const [p] = periods;
    if (p.beforeRecords) return p.to === null ? `In the Senate since before ${RECORDS_START}` : `In the Senate since before ${RECORDS_START}, until ${p.to}`;
    return p.to === null ? `In the Senate since ${p.from}` : `In the Senate ${p.from}–${p.to}`;
  }
  const spans = periods.map((p, i) => `${i === 0 && p.beforeRecords ? `before ${RECORDS_START}` : p.from}–${p.to ?? "present"}`);
  return `In the Senate ${spans.join(", ")}`;
}

const PARTICLE = /^(Mc|Mac|De|Di|Da|Du|La|Le)([A-Z].*)$/;

function capital(word: string): string {
  return word.split(/(['’-])/).map((part) => (/^['’-]$/.test(part) ? part : part.charAt(0).toUpperCase() + part.slice(1).toLowerCase())).join("");
}

/** "ACTING PRESIDENT BRENNAN" -> "Acting President Brennan"; keeps "DeFRANCISCO" as "DeFrancisco". */
export function titleCase(label: string): string {
  return label.split(/\s+/).filter(Boolean).map((word) => {
    const particle = word.match(PARTICLE);
    return particle ? particle[1] + capital(particle[2]) : capital(word);
  }).join(" ");
}

const SMALL = new Set(["a", "an", "and", "as", "at", "by", "for", "in", "of", "on", "or", "the", "to", "with"]);

/** Hearing titles arrive in capitals; others are left as written. */
export function hearingTitle(title: string): string {
  if (title !== title.toUpperCase()) return title;
  return titleCase(title).split(" ").map((w, i) => (i > 0 && SMALL.has(w.toLowerCase()) ? w.toLowerCase() : w)).join(" ");
}

const PREFIX = /^(SENATOR|ACTING PRESIDENT|ASSEMBLYMAN|ASSEMBLYWOMAN|ASSEMBLYMEMBER|ASSEMBLY MEMBER|CHAIRMAN|CHAIRWOMAN|CHAIRPERSON|CHAIR)\s+/i;

export type SpeakerKind = "senator" | "assembly" | "secretary" | "president" | "other";

/** Short form for legal citations ("Sen. Ortega"), full form for plain ones ("Sen. Marisol Ortega"). */
export function speakerForms(kind: SpeakerKind, label: string | null, fullName?: string | null): { short: string; full: string } {
  if (kind === "secretary") return { short: "the Secretary", full: "the Secretary" };
  if (kind === "president") return { short: "the President", full: fullName ? `Lt. Gov. ${fullName}` : "the President" };
  const surname = titleCase((label ?? "").replace(PREFIX, ""));
  if (kind === "senator") return { short: `Sen. ${surname}`, full: `Sen. ${fullName ?? surname}` };
  if (kind === "assembly") return { short: `Asm. ${surname}`, full: `Asm. ${fullName ?? surname}` };
  const named = titleCase(label ?? "");
  return { short: named, full: named };
}

export interface CiteInput {
  kind: "floor" | "hearing";
  date: string;
  title: string | null;
  start: number | null;
  end?: number | null;
  speaker: { short: string; full: string };
}

export function legalCite(c: CiteInput): string {
  const at = c.start == null ? "" : `, at ${legalPages(c.start, c.end)}`;
  const who = ` (remarks of ${c.speaker.short})`;
  return c.kind === "floor"
    ? `N.Y. Senate Tr., ${legalDate(c.date)}${at}${who}`
    : `N.Y. Senate Pub. Hr'g Tr., ${c.title}, ${legalDate(c.date)}${at}${who}`;
}

export function plainCite(c: CiteInput): string {
  const p = c.start == null ? "" : `, ${plainPages(c.start, c.end)}`;
  return c.kind === "floor"
    ? `NY Senate floor transcript, ${longDate(c.date)}${p} (${c.speaker.full})`
    : `NY Senate public hearing, ${c.title}, ${longDate(c.date)}${p} (${c.speaker.full})`;
}

export function outcomeText(s: { debated: boolean; outcome: string | null; ayes: number | null; nays: number | null }): string {
  const votes = s.ayes != null ? `, ${s.ayes}–${s.nays ?? 0}` : "";
  switch (s.outcome) {
    case "passed": return s.debated ? `Debated and passed${votes}` : `Passed${votes}`;
    case "lost": return s.debated ? `Debated and lost${votes}` : `Lost${votes}`;
    case "adopted": return "Adopted";
    case "laid_aside": return s.debated ? "Debated, then laid aside. No vote." : "Brought up, then laid aside. No vote.";
    default: return s.debated ? "Debated. No vote recorded." : "Read on the floor. No vote recorded.";
  }
}

export function billStatus(card: Pick<BillCard, "vetoed" | "signed" | "status"> | null): { text: string; tone: "red" | "amber" | "ink" } | null {
  if (!card) return null;
  if (card.vetoed) return { text: "Vetoed", tone: "red" };
  if (card.signed) return { text: "Signed by Governor", tone: "ink" };
  const text = card.status?.text || "Introduced";
  return { text, tone: /amend/i.test(text) ? "amber" : "ink" };
}

/** The pipeline writes New York wall-clock times without a zone; compare against New York's clock. */
export const nyClock = (date: Date) => new Date(date.toLocaleString("en-US", { timeZone: "America/New_York" }));

export function relativeTime(iso: string, now: Date): string {
  const minutes = Math.max(0, Math.round((now.getTime() - new Date(iso).getTime()) / 60000));
  if (minutes < 1) return "just now";
  if (minutes < 60) return `${minutes} min ago`;
  const hours = Math.round(minutes / 60);
  if (hours < 24) return `${hours} hour${hours === 1 ? "" : "s"} ago`;
  const days = Math.round(hours / 24);
  return `${days} day${days === 1 ? "" : "s"} ago`;
}

export const count = (n: number) => n.toLocaleString("en-US");

// Matching people by any part of their name, ignoring case, accents and apostrophes (spec 9.1).

export function fold(s: string): string {
  return s.normalize("NFD").replace(/[̀-ͯ]/g, "").replace(/['’]/g, "").toLowerCase().replace(/[^a-z0-9]+/g, " ").trim();
}

export interface Person {
  slug: string;
  name: string;
  chamber: "senate" | "assembly";
  photo: string | null;
  detail: string;
  remarks: number;
}

interface Token { start: number; end: number; folded: string; }

function tokens(name: string): Token[] {
  const out: Token[] = [];
  for (const m of name.matchAll(/[^\s-]+/g)) {
    out.push({ start: m.index!, end: m.index! + m[0].length, folded: fold(m[0]).replace(/ /g, "") });
  }
  return out;
}

/** How many original characters cover the first `n` folded characters of a token (é is one, ' is none). */
function span(name: string, token: Token, n: number): number {
  let seen = 0;
  let i = token.start;
  while (i < token.end && seen < n) {
    seen += fold(name[i]).replace(/ /g, "").length;
    i++;
  }
  return i - token.start;
}

/** Each query word must start a later part of the name, in order. Returns highlight ranges or null. */
export function matchName(query: string, name: string): [number, number][] | null {
  const words = fold(query).split(" ").filter(Boolean);
  if (!words.length) return null;
  const parts = tokens(name);
  const ranges: [number, number][] = [];
  let from = 0;
  for (const word of words) {
    const found = parts.findIndex((t, i) => i >= from && t.folded.startsWith(word));
    if (found < 0) return null;
    ranges.push([parts[found].start, parts[found].start + span(name, parts[found], word.length)]);
    from = found + 1;
  }
  return ranges;
}

function byRank(a: Person, b: Person): number {
  if (a.chamber !== b.chamber) return a.chamber === "senate" ? -1 : 1;
  return b.remarks - a.remarks;
}

export function findPeople(query: string, people: Person[], limit = 8): { person: Person; ranges: [number, number][] }[] {
  const hits: { person: Person; ranges: [number, number][] }[] = [];
  for (const person of people) {
    const ranges = matchName(query, person.name);
    if (ranges) hits.push({ person, ranges });
  }
  return hits.sort((a, b) => byRank(a.person, b.person)).slice(0, limit);
}

/** An exact slug wins; otherwise everyone who matches, so the caller can ask "Which Smith?". */
export function resolveSpeaker(value: string, people: Person[]): Person[] {
  const exact = people.find((p) => p.slug === value);
  if (exact) return [exact];
  return findPeople(value, people, people.length).map((m) => m.person);
}
```

### Task 14: The search query layer

**Files:**
- Create: `site/src/lib/query.ts`
- Test: `site/tests/unit/query.test.ts`

**Interfaces:**
- Produces:
  - `interface Branch { words: string[]; phrases: string[]; near: [string, string][] }`
  - `interface Filters { speaker?: string; bill?: string; years?: number[]; type?: "floor" | "hearing"; committee?: string }`
  - `interface ParsedQuery { branches: Branch[]; not: string[]; filters: Filters }`
  - `parseQuery(q: string): ParsedQuery`
  - `pagefindTerm(b: Branch): string`
  - `pagefindFilters(f: Filters, speakerSlug: string | null): Record<string, string | string[]>`
  - `interface Remark { url: string; turn: number; page: number | null; speaker: string | null; label: string; text: string }`
  - `remarksOf(data: { url: string; content: string; anchors: { element: string; id: string; text: string; location: number }[] }): Remark[]`
  - `keepRemark(r: Remark, b: Branch, not: string[], speakerSlug: string | null): boolean`
  - `excerpt(r: Remark, b: Branch): string` (HTML-escaped, with `<mark>` around hits)

**Rules:**
- **Grammar:** quoted phrases; `AND` (dropped, since it's the default); `OR` (splits the positive terms into branches, with AND binding tighter); `NOT x` and `-x` (global exclusions); `a NEAR b` (both words required, within 10 words of each other in one remark); `field:value` or `field:"two words"` for speaker, bill, year, type, committee.
- **Years:** `year:2019` or `year:2015-2019` (inclusive). `type:` accepts floor or hearing. `bill:` is upper-cased with the amendment letter removed (`s4597a` gives `S4597`).
- **Filters** apply to every branch. A query with only filters gives one empty branch.
- **`pagefindTerm`** joins words, quoted phrases and NEAR words with spaces.
- **`remarksOf`:** splits `content` on whitespace. Each `r-{i}` anchor starts a remark that runs to the next `r-` anchor. The `w-{i}-{page}-{key}` anchor at the same location gives page and speaker (`x` means none; page `0` means null). The remark url is `{data.url}#r-{i}`.
- **`keepRemark`:**
  - every word must start some word of the folded remark text (so `toll` matches `tolls`)
  - every phrase must appear as a folded substring on word boundaries
  - every NEAR pair must occur within 10 words
  - no NOT term may appear
  - with `speakerSlug`, only that speaker's remarks count

### Task 15: The search page

**Files:**
- Create: `site/src/pages/search.astro`, `site/src/components/SearchApp.tsx`, `site/src/pages/data/people.json.ts`, `site/src/pages/data/years.json.ts`, `site/src/pages/data/committees.json.ts`
- Test: `site/tests/e2e/search.spec.ts`

**Contract**, as in "Search results" (desktop) and the phone results:
- **Data endpoints:**
  - `people.json`: `[{slug, name, chamber, photo, detail, remarks}]`.
    - It holds **every** senator in `senators.json`, with or without a page here, so a shared surname always lists all its holders. Detail reads "District {d} · {serviceText}".
    - Assembly members who speak follow, with detail "Member of the Assembly · District {d}".
  - `years.json`: `[{year, count}]`.
  - `committees.json`: committee names with hearing counts.
- **Loading and running a search:**
  - **Loading:** `SearchApp` (`client:load`) reads `q`, `sort` (relevance, newest, oldest) and `page` from the URL, and loads Pagefind with `await import(/* @vite-ignore */ url("/pagefind/pagefind.js"))`. If loading fails it shows "Search couldn't load. Check your connection and try again."
  - **Speaker:** a `speaker:` value goes through `resolveSpeaker` over `people.json`. No match shows "No senator or Assembly member matches "{value}"." Several matches show "Which {value}?" with one button per person (name and detail); choosing one rewrites the query to `speaker:{slug}`.
  - **Running:** each branch runs `pagefind.search(pagefindTerm(branch) || null, { filters, sort: sort === "relevance" ? undefined : { date: sort === "newest" ? "desc" : "asc" } })`. Results load 20 pages at a time ("Load more" for the next 20). For each page, `remarksOf` then `keepRemark` select the remarks. Branches merge without duplicate urls.
- **Each result row:**
  - the date (`shortDate` from `meta.date`) and kind
  - the speaker name (people lookup by slug, else `titleCase(label)`) and the bill links
  - the excerpt (Charis, hits highlighted)
  - "p. N", "Copy cite" (`legalCite`, copied to the clipboard) and "Read in context" (the remark url)
- **Above the results:** "{n} remarks in {m} transcripts" plus the search time.
- **Facets** come from `search.filters` counts: Record type, Year (top 10), Senator (top 10, named through people), Committee. Clicking one appends the matching shortcut to the query and re-runs it. On phones, facets sit behind a "Filters · {n}" button that opens a sheet.
- **No results:** "Did you mean: {suggestion}?" built from `data/words/{prefix}.json`. Those files are copied to `public/data/words/` at build by `copy-photos.mjs` (rename it `copy-assets.mjs` here and update `build.mjs` and the `dev` script). The suggestion is the closest word within edit distance 2 with the highest count.
- **"Export results":** downloads Markdown of the loaded remarks (date, speaker, page, text, link).
- **The top of the page** has `<SearchBox variant="search" initial={q} />`.
